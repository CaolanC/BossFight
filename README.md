Perfect is, at its core, a real-time multi-user collaborative 3D scene editor, and as a primary use case, being developed for interior designers.
It can also be used as a framework for collaborative work, including 3d model design, games dev and an education tool for 3d maths visualisation and interaction.

Built on top of OpenGL and SDL3, in C++. Dependencies managed with cmake.

## First install SDL dependencies

Ubuntu/Linux Mint

```bash
sudo apt-get install build-essential git make \
pkg-config cmake ninja-build gnome-desktop-testing libasound2-dev libpulse-dev \
libaudio-dev libjack-dev libsndio-dev libx11-dev libxext-dev \
libxrandr-dev libxcursor-dev libxfixes-dev libxi-dev libxss-dev libxtst-dev \
libxkbcommon-dev libdrm-dev libgbm-dev libgl1-mesa-dev libgles2-mesa-dev \
libegl1-mesa-dev libdbus-1-dev libibus-1.0-dev libudev-dev
```

## To get started (copied from User Manual - remember to update submodules first):

### To generate build files

`cmake -S . -B build -G Ninja`

### To build each target:

`cmake --build build --target Server`

`cmake --build build --target GUI`

`cmake --build build --target UnitTests`

### To run on Linux

`./bin/Server`
`./bin/GUI`
`./bin/UnitTests`

### To run on Windows

`Run executables in bin folder (or, if using an IDE, should run automatically)`

## Project Structure

Project build files are generated by CMake. There are three executable targets, Server, GUI and UnitTests.
Primary source code is in src/modules, with main files being in src/apps. Unit & integration tests can be found in src/tests.
To find a detailed installation guide, please view the user manual.
